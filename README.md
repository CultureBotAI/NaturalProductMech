# NaturalProductMech

Knowledge base of **individual natural product structures** — one record per
chemical structure made by a living organism, carrying who makes it, from which
gene cluster, what it does, and the evidence for all three.

Part of the CultureBotAI Mech fleet, alongside
[AntibioticMech](https://github.com/CultureBotAI/AntibioticMech),
[TraitMech](https://github.com/CultureBotAI/TraitMech),
[CultureMech](https://github.com/CultureBotAI/CultureMech),
[MediaIngredientMech](https://github.com/CultureBotAI/MediaIngredientMech),
[HabitatMech](https://github.com/CultureBotAI/HabitatMech),
[CommunityMech](https://github.com/CultureBotAI/CommunityMech),
[CellStructureMech](https://github.com/CultureBotAI/CellStructureMech) and
[ProteinTraitsMech](https://github.com/CultureBotAI/proteintraitsmech).

will be [CC BY 4.0](LICENSE-DATA).
