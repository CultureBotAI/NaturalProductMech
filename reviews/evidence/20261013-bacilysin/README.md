PR #908. The manifest maps original temporary paths and every evidence snapshot
hash to stored artifacts or explicitly reference-only sources. Stored and
uncompressed bytes have separate SHA256 digests. Helpers and failed attempts
are historical evidence, not replay instructions.

view. `inventories` hashes selected complete TSV rows. The reviews retain their
original source commit; the historical checkpoint records the later corpus
base after the source bytes were verified unchanged.
